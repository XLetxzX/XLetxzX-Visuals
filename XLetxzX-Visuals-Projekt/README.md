# XLetxzX Visuals (1.21.11, Fabric)

Bauen (Windows): im Ordner `gradlew build` bzw. `gradle build` (JDK 21 nötig).
Fertige Datei: build/libs/XLetxzX-Visuals-1.21.11-1.0.0.jar  (die ohne -sources)
Die Mods in `nested/` werden automatisch eingebettet.

Menü: Rechts-Shift im Spiel. Konfig: .minecraft/config/xletxzx_visuals.json
Discord: Application ID ist in DiscordRpc.java eingetragen, das Bild muss im Developer Portal
unter Rich Presence > Art Assets mit dem Namen "XLetxzX" hochgeladen sein.
